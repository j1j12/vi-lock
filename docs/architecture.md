# 当前架构与安全边界

M4 负责实时接近状态与受约束的舵机动作；A7 负责图像、身份匹配、规则、界面及事件记录。
OpenAMP/RPMsg 承载跨核消息，Linux 驱动封装用户态访问。实际资源映射应以本工程源码、设备树和板端证据为准，不照搬通用 STM32 引脚示例。

视觉链：V4L2 → OpenCV → ncnn 检测/特征 → 匹配/授权规则 → 显式单次授权门控 → RPMsg → M4。
事务实验链：合成事件 → SQLite outbox → HTTPS/mTLS → 接收端事务保存/去重 → 身份匹配 ACK → 本地事务出队。

网络不应该成为实时控制的同步依赖。真实 GUI 事件上传尚未验收，不能将两个独立测试链直接视为生产闭环。
